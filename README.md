# Meu Projeto Web

## Objetivo do projeto
Praticar a criação de um site simples usando HTML, CSS e JavaScript no Visual Studio Code.

## Descrição
O projeto apresenta uma página com título, texto, imagem e um botão interativo. O CSS organiza a aparência da página e o JavaScript altera a mensagem quando o botão é clicado.

## Estrutura
- `index.html`: estrutura da página.
- `css/style.css`: estilos visuais.
- `js/script.js`: interação do botão.
- `imagens/paisagem.svg`: imagem ilustrativa.

## Como executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Abra `index.html`.
3. Se tiver o Live Server instalado, clique em **Go Live**.
4. Clique no botão da página para testar a interação.

## Tecnologias
HTML, CSS, JavaScript e Git.
